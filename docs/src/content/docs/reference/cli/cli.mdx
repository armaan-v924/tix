Manage the tix CLI itself (update, completions)

```sh frame="none"
tix cli <COMMAND>
```


## `tix cli completions`

Generate shell completions

```sh frame="none"
tix cli completions <SHELL>
```


### Arguments

| Argument | Description |
| --- | --- |
| `<SHELL>` | The shell to generate completions for<br />Accepts: `bash`, `elvish`, `fish`, `powershell`, `zsh` |


## `tix cli update`

Update tix to the latest release

```sh frame="none"
tix cli update [OPTIONS]
```


### Options

| Option | Description |
| --- | --- |
| `--dry-run` | Print what would happen without downloading or writing anything |
