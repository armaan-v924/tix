Register and clone source repositories

```sh frame="none"
tix repo <COMMAND>
```


## `tix repo add`

Register a repository in config (without cloning)

```sh frame="none"
tix repo add [OPTIONS] <REPO>
```


### Arguments

| Argument | Description |
| --- | --- |
| `<REPO>` | Full URL, `owner/repo`, or bare `repo` |

### Options

| Option | Description |
| --- | --- |
| `-a, --alias, --as <ALIAS>` | Alias to register under (defaults to the repository name) |
| `-O, --owner <OWNER>` | Owner for a bare `repo` argument (beats `[defaults].default_repository_owner`) |


## `tix repo clone`

Clone registered repositories to their code paths

```sh frame="none"
tix repo clone [OPTIONS] [REPO_ALIASES]...
```


### Arguments

| Argument | Description |
| --- | --- |
| `[REPO_ALIASES]...` | Registered aliases to clone |

### Options

| Option | Description |
| --- | --- |
| `-a, --all` | Clone every registered repository not already on disk |
