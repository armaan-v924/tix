Manage the global tix config

```sh frame="none"
tix config <COMMAND>
```


## `tix config get`

Read a value from the `[cli]` section

```sh frame="none"
tix config get <KEY>...
```


### Arguments

| Argument | Description |
| --- | --- |
| `<KEY>...` | The `[cli]` key(s) to read<br />Accepts: `tickets-directory`, `code-directory` |


## `tix config init`

Create the global config interactively

```sh frame="none"
tix config init [OPTIONS]
```


### Options

| Option | Description |
| --- | --- |
| `--force` | Overwrite an existing config file |


## `tix config set`

Set a value in the `[cli]` section

```sh frame="none"
tix config set <KEY> <VALUE>
```


### Arguments

| Argument | Description |
| --- | --- |
| `<KEY>` | The `[cli]` key to set<br />Accepts: `tickets-directory`, `code-directory` |
| `<VALUE>` | The new value (parsed as a TOML value when possible, else a string) |


## `tix config show`

Print the global config document

```sh frame="none"
tix config show
```
