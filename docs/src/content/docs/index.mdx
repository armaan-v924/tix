## Getting started

Download a binary from the [latest release](https://github.com/armaan-v924/tix/releases/latest),
put it on your `PATH`, and create the global config:

<Code code={`tix config init
tix repo add my-org/api
tix repo clone --all`} lang="sh" />

Then start work on a ticket:

<Code code={`tix setup JIRA-123 --description "Fix the login bug"
cd ~/tickets/JIRA-123`} lang="sh" />

Every command and flag is listed in the [CLI reference](/reference/cli/),
which is generated from the CLI's own argument definition — if `tix` accepts
it, it is documented there.
