Expand description

Runs a read-modify-write cycle under an exclusive advisory lock: lock → fresh parse → mutate → atomic save → unlock.

The fresh parse inside the lock is what makes concurrent writers safe: a second writer blocks on the lock, then parses the first writer’s result, so concurrency degrades to last-writer-wins at key granularity rather than lost updates (#67; complements fresh-parse-at-apply). A missing file starts from TixDocument::empty.

§Errors

Propagates errors from locking, parsing, mutate, and the atomic save.
