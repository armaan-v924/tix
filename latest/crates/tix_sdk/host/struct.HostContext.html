Expand description

Settled host values handed to a plugin, plus the user’s own args.

Paths are the real files, not staged copies — a plugin can be hand-run against arbitrary paths for debugging.

Fields§

§config_path: PathBuf

Path to the global config file.

§ticket_root: Option<PathBuf>

Path to the ticket directory (parent of .tix) — present only when the host ran inside a ticket. The absence is load-bearing: tix ticket setup creates tickets, so it runs without one.

§delta_path: Option<PathBuf>

Host-created temp file for the outbound config delta. Stdout cannot carry it — stdout belongs to the user. No file written ⇒ no changes.

§repo: Option<String>

Alias of the repo worktree cwd is inside, when it is.

§repo_dir: Option<PathBuf>

Path of that worktree.

§log_level: Option<String>

The host’s resolved log level.

§output: Option<String>

The host’s resolved output format (json/toml/default).

§color: Option<bool>

The host’s resolved color decision for this process.

§user_args: Vec<String>

Everything that was not a --tix-* flag, in order — the user’s args, untouched.

pub fn from_args( args: impl IntoIterator<Item = String>, ) -> Result<Self, SdkError>

Parses host-injected flags out of args.

  • print-cli-help as the sole argument is handled before any host flag is required (it is invoked bare): the plugin’s registered description prints and the process exits 0. Register one with Self::from_args_with_description.
  • Known --tix-* flags are collected; unknown --tix-* flags are ignored — additions never break older plugins, and checking HostContext fields doubles as capability detection.
  • --tix-protocol is compared against PROTOCOL; a mismatch is a rebuild situation, reported as such — callers should exit with PROTOCOL_MISMATCH_EXIT (or use Self::from_env_or_exit).
§Errors
  • SdkError::Message on protocol mismatch (“built for protocol N, host speaks M — rebuild”)
  • SdkError::Message when --tix-config is missing — the one flag every host invocation carries

pub fn from_env_or_exit(description: &str) -> Self

Self::from_env, turning errors into the contract’s process exits: protocol mismatch exits PROTOCOL_MISMATCH_EXIT, anything else prints to stderr and exits 1. The convenience entry point for plugin mains.
