Plugin discovery for tix --help — the “Plugins” section (design/spec.md §5.6).

Listing is best-effort by contract: a plugin whose handshake is missing, broken, slow, or malicious degrades to its bare name. The listing itself never fails, and handshake output is treated as untrusted input.
