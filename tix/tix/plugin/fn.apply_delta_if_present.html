Applies the plugin’s outbound delta, if it wrote one (spec §6).

The apply happens against a fresh parse at apply time under the exclusive lock — never the host’s startup snapshot — so it merges with whatever a nested tix or a second terminal wrote meanwhile. After the ops land, the host re-deserializes the sections it has types for: a delta that breaks a host-owned section ([engine]/[cli]/[defaults] or [ticket]) is rejected wholesale and nothing is written. Plugin sections pass unvalidated — the host has no schema for them, and the plugin validated its own on the way in. Writes outside the plugin’s own section are allowed, unsupported: applied if revalidation passes.
