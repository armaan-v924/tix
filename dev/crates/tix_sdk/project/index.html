Module project

Projects: named namespaces one level above tickets.

A project is a directory under the tickets directory that groups tickets: loose tickets live at <tickets_directory>/<KEY>/, project tickets at <tickets_directory>/<project>/<KEY>/. What makes a directory a project is the file .tix/project.toml, created empty (projects).

The marker is an assertion, not metadata. It is what lets the discovery walk (crate::discovery::discover_from) recognise a project without reading config, and it is what the listing uses too, so there is one definition of “project” rather than two that can disagree — a stray directory under the tickets directory is not a project. It is empty on purpose: adding fields to a document that exists is additive, adding a file where none existed is not, so the file is settled now and its contents wait for a reason to exist.

Projects are created implicitly on first use (Project::ensure); there is no separate “create a project” step.
