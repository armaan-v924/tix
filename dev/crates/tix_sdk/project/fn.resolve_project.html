pub fn resolve_project(
    flag: Option<&str>,
    tickets_directory: &Path,
    cwd: &Path,
) -> Result<Option<Project>, SdkError>
Expand description

Resolves the project a command is scoped to.

In order:

  1. Flag — flag names a project under tickets_directory. It need not exist yet; commands that create tickets call Project::ensure.
  2. Inferred — the nearest project above cwd, found by the discovery walk (discover_from). Like ticket discovery, this is not bounded by tickets_directory.
  3. Loose — None: tickets live directly in tickets_directory.

Pass the logical cwd (crate::discovery::logical_cwd).

§Errors

SdkError::Message when flag is not a valid project name.
