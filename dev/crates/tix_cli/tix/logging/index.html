tix_cli::tix

Module logging 

Source
Expand description

Log output for the tix binary.

Two shapes, picked by the resolved level:

  • Compact (info and quieter, the default): one line per event, just the message and its fields. Warnings and errors are prefixed warning: / error:, matching the error: <message> a failed command exits with. No timestamp, no level column, no module path: what a person running a command wants to read.
  • Detailed (debug and trace, i.e. -v or --log-level debug): tracing’s full format, with timestamps, levels, and the emitting module, for working out what tix actually did.

Both go to stderr, so stdout carries only results and stays pipeable. Colour is used only when stderr is a terminal and NO_COLOR is unset.
