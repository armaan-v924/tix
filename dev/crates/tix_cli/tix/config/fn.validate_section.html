Expand description

Re-deserializes section into the type that owns it, so an edit that broke it fails before anything reaches disk.

Only the sections tix itself models are checked. A [<plugin>] table has no type here by design — tix has no schema for one — so a path into one is written as given; the plugin is what reads it back.

§Errors

[SdkError::Message] with the deserialization diagnostic when the edited section no longer parses: an unknown key (every section type is deny_unknown_fields), or a value of the wrong type.
