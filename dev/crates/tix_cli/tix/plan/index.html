Module plan

Expand description

The plan a --dry-run prints, in whichever --output format was asked for.

Every dry run builds a Plan — one Action per thing the real run would do — and hands it to Plan::finish along with whether the real run would have succeeded. The default format prints each action’s one-line summary; JSON and TOML print the whole plan, so a script reads the same shape from every command:

{
  "dry_run": true,
  "command": "destroy",
  "would_succeed": false,
  "actions": [
    { "action": "prune", "summary": "would prune worktree api (…)", "worktree": "api", … }
  ]
}

A plan the real run would not finish is still printed, up to the action it would stop at, and then the error is returned as usual — stderr and a non-zero exit — so would_succeed and the exit code always agree.
