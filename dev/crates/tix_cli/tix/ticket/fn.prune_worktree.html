Expand description

Prunes the worktree name of the ticket at root through its source repository, then deletes its [ticket.worktrees.<name>] entry. Returns what was found on disk.

A worktree that is missing or not a git repository — usually deleted by hand — has nothing to check and nothing to remove: only git’s stale registration is pruned, if there still is one, and the entry is dropped with a warning. Whatever is at its path stays there.

The entry goes as soon as the prune lands, so a batch that fails partway leaves the ticket document agreeing with disk and a retry resumes. force prunes past uncommitted changes, discarding them.

§Errors

backing_repository’s error when entry.repo is not registered; otherwise whatever resolving the repository, pruning, or writing the ticket document returns.
