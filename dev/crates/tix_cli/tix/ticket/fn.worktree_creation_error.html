pub fn worktree_creation_error(error: &TixError, branch_flag: bool) -> String
Expand description

error from creating a worktree, worded with the way past it for the command that hit it — tix ticket setup or tix ticket add, the two that take --base. The engine states only the problem.

branch_flag says whether the command takes --branch (add does, setup derives the branch), so a branch that cannot take the base is only offered the flags that exist.
