tix crate documentation

API reference for the Rust crates behind tix.

  • tix-sdk

    Context and consistency layer shared by the CLI and plugins: config discovery and parsing, ticket discovery, the invocation contract. Start here if you are writing a plugin in Rust.

  • tix-engine

    Domain operations over already-resolved paths — repositories, worktrees, branches. No IO policy, no UI.

  • tix-cli

    The tix binary's own crate — the canonical frontend.
