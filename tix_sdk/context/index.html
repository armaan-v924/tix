Frontend context: paths resolved once at startup and handed to every subcommand.

Config path resolution is stage 1 of the read path (design/spec.md §3.3) and belongs to the frontend/SDK — the engine never reads env vars or flags. Written in tix-cli first (#52); promoted here (#96) so plugins resolve identically.

The default location is deliberately isolated in default_config_path so it can be revisited without touching resolution or call sites.
