Ticket discovery: which ticket does a command operate on?

Owned by tix-cli and written here first; promoted to tix-sdk (#96) so plugins resolve tickets identically to the canonical frontend. Explicitly not an engine concern — tix-engine takes resolved paths as given (design/spec.md §4).

Two paths in:

  • Discovery (discover_ticket_root): walk upward from the logical cwd testing for the file .tix/ticket.toml; nearest ancestor wins.
  • Override (resolve_override): a --ticket <path | id> argument, disambiguated by shape (TicketRef). Both forms are assertions, not starting points — a near-miss (e.g. a subdirectory of a ticket) errors rather than re-walking.
